# Lista de siglas

| Sigla | Significado |
|---|---|
| API | Interfaz de programación de aplicaciones (*Application Programming Interface*) |
| CIA | Confidencialidad, integridad y disponibilidad (*Confidentiality, Integrity, Availability*) |
| CSV | Valores separados por comas (*Comma-Separated Values*) |
| eBPF | *Extended Berkeley Packet Filter*, mecanismo para ejecutar programas en el kernel de Linux |
| FIM | Monitoreo de integridad de archivos (*File Integrity Monitoring*) |
| FP | Falso positivo |
| HTTP | Protocolo de transferencia de hipertexto (*Hypertext Transfer Protocol*) |
| IC | Intervalo de confianza |
| JSON | Notación de objetos de JavaScript (*JavaScript Object Notation*) |
| MTTD | Tiempo medio de detección (*Mean Time To Detect*) |
| MTTR | Tiempo medio de respuesta o de recuperación (*Mean Time To Respond* o *To Recover*) |
| NIST | Instituto Nacional de Estándares y Tecnología de los Estados Unidos (*National Institute of Standards and Technology*) |
| p95 | Percentil 95 |
| POSIX | Interfaz de sistema operativo portable (*Portable Operating System Interface*) |
| PyME | Pequeña y mediana empresa |
| SHA | Algoritmo de hash seguro (*Secure Hash Algorithm*) |
| SIEM | Gestión de información y eventos de seguridad (*Security Information and Event Management*) |
| SOAR | Orquestación, automatización y respuesta de seguridad (*Security Orchestration, Automation, and Response*) |
| TFI | Trabajo Final Integrador |
| TLS | Seguridad de la capa de transporte (*Transport Layer Security*) |
| TOCTOU | Del momento de la verificación al momento del uso (*time of check to time of use*) |
| UTN | Universidad Tecnológica Nacional |
| VN | Verdadero negativo |
| VP | Verdadero positivo |
| WSL2 | Subsistema de Windows para Linux, versión 2 (*Windows Subsystem for Linux*) |
